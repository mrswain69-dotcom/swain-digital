# Swain Digital Ltd

Public company website for Swain Digital Ltd, company number 16886922.

## Structure

- `public/` — static website, company contact and privacy pages, optimised brand assets.
- `vercel.json` — Vercel deployment settings. No dependencies or build step required.

## Deploy

Import `mrswain69-dotcom/swain-digital` into the intended Vercel team. Select **Other** as framework, leave install and build commands empty, and set output directory to **public**. Deploy the **main** branch and add **swain.digital** in Project Settings → Domains.

## Content follow-ups

- Add a monitored public company email alias after it has been created and tested. The owner's personal email is deliberately not included.
- Add the verified public Phase Shift URL. Current support instructions direct members to the in-product Support page.
- If adding a contact form, connect and test a server-side mail delivery service, add spam protection, and update the privacy notice for its data handling. Never expose credentials in client code.
